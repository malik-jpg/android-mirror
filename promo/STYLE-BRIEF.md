# Promo Video — Style Brief & Rundown (draf, menunggu persetujuan)

**Format:** 1080×1920 (9:16) untuk TikTok / IG Reels / FB Pro / YT Shorts · 30 detik · tanpa VO (teks + musik bebas ditambah sendiri saat edit) · render di PC sendiri.

## Style brief

| | |
| :-- | :-- |
| Produk & rasa | Android Mirror — *praktis, mulus, berkelas* |
| Konsep (3 kandidat) | **① Estafet benda** — satu foto berjalan HP → PC → folder, lalu file balik PC → HP · ② Sebelum/sesudah — garis pembelah "bolak-balik pegang HP" vs "semua dari PC" · ③ Satu shot kontinu di meja kerja |
| **Dipilih** | **① Estafet benda** — nilai produk persis "sesuatu berpindah di antara dua perangkat"; dua arah perjalanan itu nanti bersilang membentuk **X** di logo |
| Sidik jari | estafet benda · 6 babak · benda pahlawan = satu foto · pembuka: jepretan kamera HP · penutup: dua jalur emas bersilang jadi logo X |
| Palet | Navy `#1E324C` (latar — cincin logo) · Emas `#D4A84B` (utama — silang & cincin logo) · Krem `#F4EEE0` (latar terang — isi logo) · Merah `#C8261F` (aksen — segitiga logo). Hijau `#3DDC84` hanya muncul di UI asli aplikasi |
| Font | Display **Fraunces** (serif berkarakter, senada huruf di logo) + **DM Sans**; teks di dalam mockup = Segoe UI (font asli aplikasi) |
| Penekanan teks | Tanpa sorotan kotak/pill — satu kata kunci per kalimat berwarna emas; sentence case, tanpa titik |
| Latar | Navy bergradien + butiran halus + vignette; **berganti ke krem** saat foto "mendarat" di folder PC (pemicu: jendela folder mekar memenuhi frame), kembali navy saat file dikirim balik |
| Tanda tangan gerak | **Jalur emas yang menggambar dirinya** — setiap perpindahan HP ⇄ PC adalah garis emas melengkung yang ditempuh benda |
| Gerak latar | Sapuan cahaya emas lembut per segmen + butiran hidup |
| Gaya objek | Flat dengan kilau tipis (HP & monitor vektor), screenshot UI asli melayang dengan bayangan lebar |
| Transisi | Dibawa benda (foto keluar layar HP → masuk jendela PC; folder mekar → ganti latar); satu cut keras ke penutup |
| Momen istimewa | Dua jalur emas (HP→PC & PC→HP) bersilang → cincin navy & emas menutup → jadi ikon X aplikasi |

## Rundown (30 dtk)

| Detik | Babak | Teks di layar | Visual |
| :-- | :-- | :-- | :-- |
| 0–2.5 | Jepret | Fotonya di **HP** | Close-up layar HP, tombol shutter ditekan, kilat putih, foto jadi thumbnail |
| 2.5–7 | Muncul di PC | Layarnya di **PC** | Kamera mundur: HP di meja, jalur emas menggambar ke monitor; layar HP hidup di jendela Android Mirror |
| 7–12 | Kontrol | Kontrol pakai **mouse** | Kursor besar scroll & klik di jendela mirror, HP fisik ikut bergerak; gelombang suara keluar dari speaker |
| 12–18 | Ambil | Ambil ke **PC** | Kursor klik 📁 File → jendela File (screenshot asli) mekar → foto dipilih → terbang di jalur emas → folder mekar, latar jadi krem |
| 18–22 | Kirim balik | Kirim ke **HP** | File diseret dari folder kembali ke HP, jalur emas kedua menggambar arah sebaliknya, latar kembali navy |
| 22–25 | Tanpa kabel | Tanpa **kabel** juga bisa | Kabel tercabut, ikon Wi-Fi berdenyut, mirror tetap jalan |
| 25–30 | Logo | **Android Mirror** · gratis, link di bio | Dua jalur emas bersilang jadi X, cincin menutup → ikon aplikasi; tahan 2 dtk |
